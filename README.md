# CS5488 Project

A repository for the course project in CS5488 Big Data Algorithms and Techniques.

## Problem Description

In this course project, we need to select a dataset to produce valuable insights by making use of

- Data analytical skills (e.g., plots, tables), and
- Parallel computing solution (e.g., Hadoop, Spark)

to demonstrate that we understand the course.

## Milestones and Submissions

- Week 4 (21/9): Confirm Grouping (no more changes to grouping). [Link](https://canvas.cityu.edu.hk/courses/70594/groups#).
